# Epic 5: Pathfinding Primitives (CA-4) — Phase 4 Opens

**Objective:** Deliver `setTraversalCosts` + `findPath` — A\* over the CSR adjacency graph inside the Worker with cooperative yielding — validating the Worker call harness that CA-5/6/8 build on.
**Scope:** Incorporates PRD §"Acceptance Criteria — Epic 5". Normative detail: ROADMAP §9 (CA-4, F-4.1, F-4.7).

**Entry gate:** `docs/audits/phase-3-audit.md` is `[PASS]` and merged to `main`. Do not start otherwise.

**Verifiable & Measurable Success Criteria:**

- **Latency:** a 500-sector path over a 10,000-sector graph resolves in < 2 ms in the Worker; P95 over the fixture's 50 pairs < 2 ms on reference hardware.
- **Correctness:** returned `Uint16Array` paths are contiguous in the adjacency graph, start/end correct, and cost-optimal against a reference Dijkstra check on ≥ 5 fixture pairs.
- **Failure semantics:** unreachable pairs (graph-disconnected, per Task 5.1) reject with `PathNotFoundError`. **Resolved (BDFL ruling, ROADMAP §9/§12.5 Hardening Sync):** `findPath` before `setTraversalCosts` has resolved at least once rejects with `CostsRequiredError` (canonical, created in Epic 1 Task 1.2). Rationale: explicit failure beats silently pathing on costs the consumer never supplied — the engine never invents game state (P-4), and hop-count paths would look plausible while being wrong for the consumer's game. Do not reuse `MappingRequiredError` here; its widened trigger covers mapping/aggregation preconditions only.
- **Isolation:** `SimulationClock` drift ≤ ±2 ms while a pathfinding burst runs.

## Tasks

### Task 5.1 — Fixture: `test/fixtures/pathfinding/grid-10k.json`

**PRD Reference:** §"Acceptance Criteria — Epic 5"; ROADMAP §9 CA-4 Fixture.

**Work:**

- Generate via a new script `test/fixtures/pathfinding/generate-grid-10k.js` (same convention as `test/fixtures/generate-fixtures.js`: committed alongside its output, re-runnable) a 100×100 grid graph: 10,000 nodes, 4-connected CSR arrays, `traversalCosts: Uint8Array` with values drawn from the range **1–255 (never 0)** via a hand-rolled deterministic PRNG implemented inline in the script (e.g. mulberry32, `seed=42`) — do not add a PRNG package dependency (none is currently installed); a small inline generator function guarantees the same script always reproduces identical bytes. Generate 50 start/end pairs (same seed stream) including pairs with expected path lengths ≥ 500.
- **Unreachability is produced by graph disconnection, not cost:** carve out one fully walled-off rectangular sub-region by omitting its boundary edges from the CSR adjacency arrays (no adjacency edges cross into/out of the region), and include at least one pair with one endpoint inside that region and one outside. `traversalCosts` never encodes impassability — finite edge costs can never make a connected node unreachable to A\*, so cost only affects path preference/optimality, and excluding 0 from the cost range keeps the A\* heuristic (Task 5.2) well-defined.
- Schema: `{width, height, adjacencyPointers, adjacencyNeighbors, traversalCosts, pairs: [{start, end, expectedCost|null}]}` — `expectedCost` computed by a reference Dijkstra in the generator; `null` marks unreachable.

**Done when:** fixture committed; `node test/fixtures/pathfinding/generate-grid-10k.js` reproduces it byte-identically (seed determinism, same engine — this is a one-time committed artifact, not regenerated by test runs).

### Task 5.2 — `SpatialGraph` (Worker A\*)

**PRD Reference:** §"New modules"; ROADMAP §9 CA-4.

**Work:**

- Create `src/worker/SpatialGraph.ts`: constructed from `adjacencyPointers`/`adjacencyNeighbors` + `traversalCosts`; `findPath(start, end): Promise<Uint16Array>` — A\* with binary-heap open set over typed arrays (scores in preallocated `Float32Array`, cameFrom in `Uint16Array` using `0xFFFF` as the "no predecessor" sentinel for `start`, per §12.3; zero per-node object allocation, PR-3), heuristic `h(n) = euclideanDistance(centroid(n), centroid(goal)) * minPossibleCost` — **multiply, never divide** (dividing by cost would divide-by-zero if a 0 cost ever appeared; Task 5.1 excludes 0 from the fixture's cost range for exactly this reason). Admissibility holds as long as `minPossibleCost` is ≤ the cheapest edge cost actually present in the loaded graph (e.g. `1`, matching the fixture's 1–255 range).
- `await yieldIfNeeded(state)` inside the expansion loop (≤ 8 ms slices).
- Throws `PathNotFoundError` when the open set empties.

**Done when:** Node-mode unit tests over small hand-built graphs pass (shortest path, tie determinism, unreachable → `PathNotFoundError`); zero DOM/Three.js imports (`git grep -E "three|document|window" src/worker/SpatialGraph.ts` empty).

### Task 5.3 — Public API: `setTraversalCosts` + `findPath`

**PRD Reference:** §"Public API delta".

**Work:**

- Worker handlers: `setTraversalCosts` (receive Transferable `Uint8Array`, length must equal `sectorCount` — validate, store, (re)build `SpatialGraph`), `findPath` (delegate; `RESULT` carries the path `Uint16Array` via transfer list).
- `MapEngine.setTraversalCosts(costs: Uint8Array): Promise<void>` — transfers ownership by including `costs.buffer` itself (the caller's actual `ArrayBuffer`, never a copy/slice of it) in the `postMessage` transfer list; document that replacement needs a fresh allocation, §4. `MapEngine.findPath(startId: number, endId: number): Promise<Uint16Array>`.
- Both are in-flight-registered so Epic 3's lifecycle invalidation rejects them on `loadMap`/`dispose`.
- Enforce the `findPath`-before-`setTraversalCosts` precondition: reject with `CostsRequiredError` (ruled — see Success Criteria "Failure semantics"); document the behavior in TSDoc, and add a test asserting the rejection type.
- Update `example/src/main.ts`: click two sectors → path computed and visualized (e.g., palette highlight of path sectors).

**Done when:** browser-mode integration test loads a small real map through the standard `loadMap()` pipeline (**not** `grid-10k.json` — that fixture is a synthetic CSR-only JSON with no corresponding bitmap and cannot be loaded via `loadMap()`; see Task 5.4 for how the 10k fixture is actually exercised) and round-trips a path through the real Worker; `costs.byteLength === 0` on Main post-call (this only holds if `costs.buffer` was the transferred buffer, not a copy — see above); lifecycle rejection test extended to `findPath`.
